# Python Lists

## Create a list

```python
numbers = [1, 2, 3]
```

## Append

```python
numbers.append(4)
```

## Remove

```python
numbers.remove(2)
```

## Sort

```python
numbers.sort()
```

## Reverse

```python
numbers.reverse()
```

## Useful methods

- append()
- extend()
- insert()
- remove()
- pop()
- clear()
- sort()
- reverse()
- index()
- count()

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Append | O(1) |
| Insert | O(n) |
| Remove | O(n) |
| Search | O(n) |
